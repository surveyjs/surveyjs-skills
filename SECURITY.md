# Security policy

## Supported versions

Security fixes are made on the default branch and included in the next release. Only the latest
release and the current `main` branch are supported.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository. Please do not disclose
a vulnerability in a public issue. If private reporting is unavailable, email
`info@devsoftbaltic.com` with `surveyjs-skills security` in the subject.

Include the affected skill or manifest, a minimal reproduction, the expected impact, and any
suggested remediation. Relevant reports include unsafe or malicious instructions, credential or
private-data exposure, command-injection risks, compromised upstream references, and provider
manifest or workflow behavior that could execute unintended code.

We will acknowledge reports as soon as practical, investigate them, and coordinate disclosure
after a fix is available.
